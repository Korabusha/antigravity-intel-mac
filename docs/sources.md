# Источники

Только **100% бесплатные** GitHub-проекты, код, сигнатуры или идеи которых
вошли в этот гайд. Ничего платного, ничего с пробным периодом, ничего
непроверенного здесь нет.

Все репозитории проверены вручную **11 ноября 2026**: README, лицензия через
GitHub API, наличие обязательной оплаты или платных ключей.

Обозначения:

- **использовано** — код, сигнатуры или подход вошли в проект;
- **зеркало** — копия удалённого оригинала.

- Ссылка: <https://github.com/trustybird/agy-unlock>

## 4. confeden/Antigravity — rename/asar

- Ссылка: <https://github.com/confeden/Antigravity>
- Лицензия: restricted (NOASSERTION) — код открыт, но права не оформлены
  стандартной лицензией.
- Что взяли: **только идеи из публичного README** — rename-гейт
  (`ineligible -> inexigible`) и подход к `app.asar`. Код не копировался.
- Проверка: бесплатный. Для запуска нужен **бесплатный** ключ из закреплённого
  сообщения Telegram-группы `@nova_txt`, свой для каждой версии. Платить
  ничего не нужно, донат необязательный.
- Статус: **использовано (идеи)**
